I practiced different CSS selectors by creating a webpage with 5+ elements. I used the universal selector * to reset margin, padding and set box-sizing for all elements. I used element selectors like h2, h3 and p to style headings and paragraphs directly. I used a class selector .card to style three service cards with the same design and .highlight for a special card variation. I used an ID selector #main-header and #special-offer to style specific unique sections with distinct backgrounds. I used grouping selectors like h1, h2, h3 and header, footer to apply common styles and reduce code duplication. For cascade and specificity, I created conflicting rules for p tag where p {color: gray} with low specificity was overridden by .card p {color: #333} which has higher specificity, and also showed that when specificity is same, the later rule in the stylesheet wins due to cascade.
